Technical Overview  ## Objective  This Technical Requirements Document (TRD) defines the complete technical architecture, development standards, software stack, system modules, integrations, and implementation guidelines required to build the FirstTap Hackathon MVP.  The primary objective of the MVP is to demonstrate a fully voice-controlled AI Digital Mentor capable of teaching a user how to use Google Pay in Tamil through an interactive smartphone simulation, AI-guided demonstrations, real-time assistance, and contextual conversations.  The architecture must prioritize modularity, scalability, maintainability, and future expansion while ensuring smooth performance during the hackathon demonstration.  ---  # 2. System Architecture  The application follows a modular client-server architecture with AI-assisted services.  ```  User     │     ▼  Frontend (Next.js)     │     ├── Voice Controller     ├── AI Avatar     ├── Lesson Manager     ├── Phone Simulator     ├── Practice Sandbox     ├── Mentor Overlay     │     ▼  Backend API (Next.js API Routes)     │     ├── Gemini AI     ├── Lesson Engine     ├── Conversation Manager     ├── Progress Manager     │     ▼  JSON Lesson Data  ```  The architecture separates presentation, business logic, lesson content, and AI communication to ensure clean code organization and future extensibility.  ---  # 3. Technology Stack  ## Frontend  - Next.js 15 (App Router)  - React 19  - TypeScript  - Tailwind CSS  - Framer Motion  ## Backend  - Next.js API Routes  - Node.js Runtime  ## Artificial Intelligence  - Google Gemini API  - Context-aware Prompt Engineering  - Structured Conversation Management  ## Voice Technologies  - Web Speech API    - Speech Recognition    - Speech Synthesis  ## Avatar  - FBX/GLB 3D Character  - React Three Fiber (Future Enhancement)  - Three.js  - @react-three/drei  ## Development Tools  - VS Code  - Git  - GitHub  - Antigravity AI  ---  # 4. Core Application Modules  The MVP consists of independent reusable modules.  ### Splash Module  Responsibilities  - Display FirstTap branding  - Load assets  - Initialize voice services  - Transition smoothly to greeting  ---  ### AI Mentor Module  Responsibilities  - Avatar rendering  - Greeting animation  - Voice synchronization  - Speaking state  - Listening state  - Mentor expressions  ---  ### Voice Controller  Responsibilities  - Continuous speech recognition  - Voice activation  - Speech synthesis  - Tamil language support  - Automatic microphone management  - Silence detection  The application should minimize manual microphone interaction.  ---  ### Conversation Manager  Maintains conversation context.  Stores  - Current lesson  - Current screen  - Current step  - User question  - AI response  - Conversation history  This enables Gemini to answer questions contextually rather than as isolated prompts.  ---  ### Lesson Manager  Responsible for  - Loading lesson JSON  - Lesson sequencing  - Timing control  - Voice synchronization  - Subtitle synchronization  - Screen transitions  - Lesson completion  Future lessons should only require new JSON files.  ---  ### Phone Simulator  Provides a fully simulated smartphone.  Screens include  - Home Screen  - Google Pay Home  - Contact Selection  - Amount Entry  - PIN Entry  - Payment Processing  - Success Screen  No real payment APIs are used.  ---  ### Practice Sandbox  A simulated learning environment.  Responsibilities  - Allow learner interaction  - Detect mistakes  - Detect inactivity  - Trigger AI guidance  - Resume learning  The sandbox must never connect to real financial services.  ---  ### Digital Confidence Assessment  Calculates learner progress.  Evaluation Parameters  - Lesson Completion  - Practice Completion  - Number of Mistakes  - Number of Hints  - Questions Asked  - Overall Performance  Outputs  Digital Confidence Score (DCA)  ---  # 5. Data Architecture  The MVP primarily uses structured JSON files.  Primary lesson format  ```  Lesson  │  ├── Metadata  ├── Introduction  ├── Lesson Steps  ├── Voice  ├── Subtitles  ├── Animations  ├── Timing  ├── Practice Rules  └── Completion  ```  Advantages  - Easy maintenance  - No hardcoded lessons  - Supports unlimited future lessons  ---  # 6. API Requirements  ## Gemini Conversation API  Responsibilities  - Receive user query  - Maintain lesson context  - Generate mentor response  - Return structured reply  Input  ```  Lesson Context  Conversation History  User Speech  ```  Output  ```  AI Response  Suggested Actions  Conversation State  ```  ---  # 7. Voice Requirements  The application follows a Voice-First design.  Conversation Cycle  ```  Greeting  ↓  Listening  ↓  Thinking  ↓  Speaking  ↓  Listening  ```  Requirements  - Automatic listening after speaking  - Tamil speech recognition  - Tamil speech synthesis  - Subtitle synchronization  - Continuous interaction  - Minimal button dependency  ---  # 8. Performance Requirements  Application startup:  < 3 seconds  Voice response:  < 2 seconds  Lesson transition:  < 500 ms  Animation:  60 FPS target  Responsive layout  Desktop demonstration optimized  ---  # 9. Security & Privacy  The MVP should not collect or store sensitive personal information.  Guidelines  - No real payment processing  - No banking authentication  - No financial transactions  - No password storage  - API keys stored in environment variables  - HTTPS-ready architecture  Practice Mode operates entirely within a simulated environment.  ---  # 10. Scalability & Engineering Standards  The project must follow clean software engineering principles.  Requirements  - Modular components  - Single Responsibility Principle  - Reusable hooks  - Config-driven lesson engine  - Type-safe TypeScript  - Component-based architecture  - Separation of UI and business logic  Future services such as DigiLocker, WhatsApp, Government Services, Healthcare, and Banking should be added by creating new lesson configuration files without modifying the core lesson engine.  This architecture ensures that FirstTap evolves from a hackathon MVP into a scalable AI-powered multilingual digital learning platform capable of supporting millions of users while maintaining maintainable, production-ready code quality.   `
